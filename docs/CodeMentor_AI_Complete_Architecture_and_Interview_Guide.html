Full-Stack Project Documentation

CodeMentor AI

Complete Technical Architecture, REST/WebSocket APIs, Integration & Technical Interview Guide

1. Executive Summary & Project Purpose

CodeMentor AI is a full-stack enterprise platform developed using Spring Boot 3 (Java 21) and React 19 (Vite). It provides intelligent automated code analysis, multi-developer real-time collaboration, interactive AI mock interviews, and personalized career roadmaps.

Key Capabilities

  • Multi-Source Code Review: Review single snippets, upload multi-file ZIP projects, or directly connect GitHub repositories via Personal Access Tokens (PAT).
  • Dual-LLM Engine: Sub-500ms snippet feedback powered by Groq (Llama 3.1 8B Instant) and whole-codebase reviews powered by Google Gemini 1.5 Pro (1M+ token context).
  • Real-Time Collaboration: Interactive multiplayer coding rooms powered by Spring WebSocket + STOMP, Monaco Editor synchronization, and live chat with an automated @AI Mentor bot.
  • Mock Interview Simulator: Dynamic MCQ and Coding technical question generation with automated evaluation.
  • Adaptive Skill Roadmaps: Milestone learning roadmaps automatically computed from users' historical code review scores.
  • Enterprise Security: Stateless JWT authentication, role-based authorization (USER/ADMIN), and BCrypt hashing.

3. Complete API Specifications

3.1 Authentication (/api/v1/auth)

  • POST /api/v1/auth/register: Registers user with username, email, password. Returns signed JWT and role.
  • POST /api/v1/auth/login: Validates credentials and returns JWT token (24h lifespan).

3.2 AI Code Reviews (/api/v1/reviews)

  • POST /api/v1/reviews/analyze: Body: { code, language, title }. Runs Groq LLM, calculates security/performance scores, saves Review & ReviewHistory.
  • GET /api/v1/reviews/history: Fetches past code reviews belonging to authenticated user.

3.3 GitHub Integration (/api/v1/github)

  • POST /api/v1/github/connect: Securely links user's GitHub Personal Access Token (PAT).
  • GET /api/v1/github/repos: Calls GitHub API to list all user repositories.
  • POST /api/v1/github/analyze: Downloads repository zipball stream, unpacks code files in-memory via ZipUtils, and dispatches to Gemini Pro for architectural synthesis.

3.4 Real-Time WebSockets (/ws-collaboration)

  • /app/collab/{roomId}/code: Receives live code edits, broadcasts to /topic/collab/{roomId}/code.
  • /app/collab/{roomId}/chat: Broadcasts room chat. Automatically triggers Groq LLM if @AI is tagged.

4. Frontend & Backend Integration Flow

How does JWT Authentication & Token Lifecycle work between React and Spring Boot?
  1. User inputs credentials in Login.jsx. The public Axios client api.post('/auth/login') is called.
  2. Backend authenticates via AuthenticationManager, generates an HMAC-SHA256 token using JwtService, and returns it.
  3. Frontend saves the token and user profile in localStorage and React AuthContext.
  4. For subsequent requests, apiPrivate has an Axios Request Interceptor that reads the token and injects Authorization: Bearer <token> into the HTTP headers.
  5. The Axios Response Interceptor monitors incoming responses: if a 401 Unauthorized status occurs (expired token), it clears localStorage and redirects the user to /login.
  6. In Spring Boot, JwtAuthenticationFilter intercepts the request before UsernamePasswordAuthenticationFilter, validates the token, extracts the email, builds UsernamePasswordAuthenticationToken, and populates SecurityContextHolder.

5. Top Technical Interview Questions & Answers

Q1: Why did you implement a multi-model AI strategy instead of using just one provider?
"Different AI models excel at different operational profiles:
  • Groq Cloud (Llama 3.1 8B Instant) delivers sub-500 millisecond response times due to specialized Language Processing Units (LPUs). This makes it ideal for single-file reviews and interactive @AI responses in live chat.
  • Google Gemini 1.5 Pro features an ultra-large context window (1M+ tokens), which is required when ingesting an entire multi-file codebase or GitHub repository. Using Groq for an entire repository would exceed standard context limits, while using Gemini for quick single-file snippets would introduce higher latency."
Q2: How did you solve the echo loop problem in the collaborative Monaco editor?
"In real-time multi-cursor collaboration, when User A writes code, the editor emits an update to the WebSocket broker. The broker broadcasts the update to all room subscribers, including User A. If User A unconditionally updates their editor state, it creates cursor jumps, text duplication, and infinite feedback loops.

Solution: We implemented client-side origin tagging:
  • Each browser tab generates a unique client UUID on mount: const clientId = useRef(uuidv4()).
  • Outgoing code packets include: { roomId, content, language, senderId: clientId.current }.
  • Upon receiving a broadcast from /topic/collab/{roomId}/code, the client checks:
    if (message.senderId !== clientId.current) { setCode(message.content); }
This guarantees zero-echo typing for the author while providing instantaneous updates to all other peers."
Q3: How are repository ZIP files processed without exhausting server memory or disk storage?
"Instead of writing incoming archives to the server's local file system (which introduces disk I/O bottlenecks and temporary file cleanup bugs), our ZipUtils class processes byte streams directly in memory using Java's ZipInputStream.

As each ZipEntry is read, we apply heuristic filtering to skip build artifacts, dependencies, and version control directories (e.g., .git, node_modules, target, dist, .idea). Only recognized source code extensions are buffered and assembled into our architectural evaluation prompt."

1. Spring Security JWT Authentication Filter

package com.codementor.ai.security;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.lang.NonNull;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
import java.io.IOException;

@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtService jwtService;
    private final UserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(
            @NonNull HttpServletRequest request,
            @NonNull HttpServletResponse response,
            @NonNull FilterChain filterChain
    ) throws ServletException, IOException {

        final String authHeader = request.getHeader("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            filterChain.doFilter(request, response);
            return;
        }

        final String jwt = authHeader.substring(7);
        final String userEmail = jwtService.extractUsername(jwt);

        if (userEmail != null && SecurityContextHolder.getContext().getAuthentication() == null) {
            UserDetails userDetails = this.userDetailsService.loadUserByUsername(userEmail);

            if (jwtService.isTokenValid(jwt, userDetails)) {
                UsernamePasswordAuthenticationToken authToken = new UsernamePasswordAuthenticationToken(
                        userDetails, null, userDetails.getAuthorities()
                );
                authToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
                SecurityContextHolder.getContext().setAuthentication(authToken);
            }
        }
        filterChain.doFilter(request, response);
    }
}

2. Real-Time Collaboration Controller with @AI Detection

package com.codementor.ai.controller;

import com.codementor.ai.client.GroqClient;
import com.codementor.ai.dto.ChatMessage;
import com.codementor.ai.dto.CodeUpdateMessage;
import lombok.RequiredArgsConstructor;
import org.springframework.messaging.handler.annotation.DestinationVariable;
import org.springframework.messaging.handler.annotation.MessageMapping;
import org.springframework.messaging.handler.annotation.Payload;
import org.springframework.messaging.simp.SimpMessagingTemplate;
import org.springframework.stereotype.Controller;
import java.time.LocalDateTime;

@Controller
@RequiredArgsConstructor
public class CollaborationController {

    private final SimpMessagingTemplate messagingTemplate;
    private final GroqClient groqClient;

    @MessageMapping("/collab/{roomId}/code")
    public void handleCodeUpdate(@DestinationVariable String roomId, @Payload CodeUpdateMessage message) {
        messagingTemplate.convertAndSend("/topic/collab/" + roomId + "/code", message);
    }

    @MessageMapping("/collab/{roomId}/chat")
    public void handleChatMessage(@DestinationVariable String roomId, @Payload ChatMessage message) {
        message.setTimestamp(LocalDateTime.now());
        message.setAiResponse(false);
        messagingTemplate.convertAndSend("/topic/collab/" + roomId + "/chat", message);

        if (message.getContent() != null && message.getContent().contains("@AI")) {
            String prompt = "You are an AI Code Mentor in a live room. " +
                            message.getSenderName() + " asked: " + message.getContent();
            try {
                String aiResponse = groqClient.generateContent(prompt);
                ChatMessage aiMessage = ChatMessage.builder()
                        .roomId(roomId)
                        .senderName("AI Mentor")
                        .content(aiResponse)
                        .timestamp(LocalDateTime.now())
                        .isAiResponse(true)
                        .build();
                messagingTemplate.convertAndSend("/topic/collab/" + roomId + "/chat", aiMessage);
            } catch (Exception e) {
                System.err.println("AI Chat error: " + e.getMessage());
            }
        }
    }
}

3. Production Axios Interceptors (Client-Side)

import axios from 'axios';

const BASE_URL = 'http://localhost:8080/api/v1';

export const apiPrivate = axios.create({
    baseURL: BASE_URL,
    headers: { 'Content-Type': 'application/json' }
});

apiPrivate.interceptors.request.use(
    (config) => {
        const token = localStorage.getItem('token');
        if (token) {
            config.headers.Authorization = `Bearer ${token}`;
        }
        return config;
    },
    (error) => Promise.reject(error)
);

apiPrivate.interceptors.response.use(
    (response) => response,
    async (error) => {
        const originalRequest = error.config;
        if (error.response?.status === 401 && !originalRequest._retry) {
            originalRequest._retry = true;
            localStorage.removeItem('token');
            localStorage.removeItem('user');
            window.location.href = '/login';
        }
        return Promise.reject(error);
    }
);
